个人桌面版 v0.1.0，Windows x64 试用发行。

- 本人飞书私聊配对，登记本机项目并新建或接管 Claude Code 会话。
- 任务与附件持久化、任务取消、异常核对、结果卡片补发。
- Windows 系统凭据存储与执行进程回收。
- 经过 Windows runner 上的自动回归及打包程序启动检查。

下载并解压 OnCallAgent-Windows-x64.zip，保留整个目录，启动 OnCallAgent.exe。首次运行需选择本机已安装并完成认证的 claude.exe，再配置飞书企业自建机器人并配对本人私聊。

本试用包未进行 Windows 代码签名。真实飞书与用户模型凭据仍需在本机联调。SHA256SUMS.txt 可用于校验 ZIP。
