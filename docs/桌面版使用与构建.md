# Windows 个人桌面版

在仓库 Actions 的 **Windows desktop** 页面选择分支构建。推送到 `codex/personal-desktop` 或 `main` 会自动运行。成功后下载运行详情底部的 **OnCallAgent-Windows-x64** artifact，解开里面的 ZIP，保留整个 OnCallAgent 文件夹并运行 `OnCallAgent.exe`。同目录的 `OnCallEngine.exe` 与 `_internal` 是程序依赖。试用包未做 Windows 代码签名。

1. 在自己的 Windows 电脑上安装 Claude Code，确认用当前用户执行 `claude --version` 成功，并完成模型认证。桌面设置中选择原生 `claude.exe`。
2. 配置飞书企业自建应用的机器人和长连接事件 `im.message.receive_v1`，发布并将应用的可用范围设为包含本人。桌面填入 App ID 和 Secret 后保存并连接。凭据通过系统凭据存储管理。
3. 生成配对命令，从本人飞书私聊发给机器人，在桌面核对并确认身份。选择项目、新建会话，或在终端退出已有会话后接管。默认只读，可以在登记项目时选择允许编辑。
4. 私聊发需求或先发图再发文字。使用 `/status`、`/sessions` 或 `/stop 任务号`。运行结果和投递状态可在任务页查看。强制停止后显示“结果未知”时，先核对仓库和会话历史，再从桌面重新接管。
5. Windows 数据存放在 `%LOCALAPPDATA%\OnCallAgent`。关闭窗口隐藏到托盘，选择托盘的“退出应用”才会停止引擎。

开发使用 Python 3.12，在虚拟环境运行 `python -m pip install -e ".[desktop,bundle,dev]"`。用 `oncall-desktop` 启动源码版，`python -m pytest -q` 运行回归。Actions 在 Windows x64 上测试，运行 PyInstaller 和 `packaging/check_bundle.py`，通过打包程序的 IPC 和 GUI 启动检查后上传 ZIP。自动测试使用临时数据目录；真实飞书和模型账号需单独联调。
